Проверка версии 1.1.0
====================

Целевая версия: Minecraft Java 1.20.1, Fabric Loader 0.16.10, Fabric API 0.92.2+1.20.1.

Сборка: Gradle 8.7, Fabric Loom 1.6.12, JDK 17.0.21. Java-байткод компилируется для Java 17.

Встроенная текстура: пользовательский `atlas.png` из `atlas.zip`, PNG RGB 1254×1254. Изображение сохранено без изменений; соответствие исходному файлу проверено по SHA-256 и по содержимому готового JAR.

Автоматические проверки:

- Девять JUnit-тестов: разбор чата; валидация полей; подробный контекст по умолчанию и совместимость со старым JSON; многострочный Unicode-контекст; сохранение файла и сохранность прежних данных при неверных значениях.
- Четырнадцать Fabric GameTest в настоящем headless-мире: стабильный ID, имя, произвольный NBT и режим инструмента при выпуске/возврате; повторный подбор и копия ID; сохранённая привязка выгруженной сущности; чужой владелец; заполненный инвентарь, включая творческий режим; защита от урона и /kill; произвольные игровые команды; права на серверные настройки, применение и конфликты версий; строительство с отменой; HTTP-цикл AI и передача пользовательского системного контекста; скорость инструмента, реальные Fortune X / Silk Touch и лут; разрушение бедрока с выпадением предмета; свободный полёт и остановка; автоматический комментарий о враге, ограничение частоты и отключение.
- Автоматический тест настоящего графического клиента Minecraft под Xvfb: кнопка в настройках, список модов, прокрутка, неверные значения, многострочный редактор, сохранение на диск и применение без перезапуска, восстановление полного исходного контекста. Скриншоты находятся в `docs/screenshots/`.

В игровых тестах используется отдельный временный мир. Тестовый мод не включается в игровой JAR.

Реальный внешний AI-провайдер не проверялся: платный API-ключ не задан. Вместо него проверен совместимый HTTP-контракт и выполнение ответа. Графический клиент и меню проверены; визуальное положение модели с пользовательскими анимациями рук и совместимость с шейдерами требуют проверки в конкретной сборке. Свечение ядра — full-bright, без динамического освещения блоков.

Произвольные игровые команды дают широкие возможности, но не гарантируют безошибочного выполнения любого естественного запроса: это зависит от модели и синтаксиса команд Minecraft 1.20.1. Отмена распространяется на встроенный строитель, а не на команды fill/setblock.
