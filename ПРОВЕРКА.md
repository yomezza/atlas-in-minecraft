Проверка версии 1.0.0
====================

Целевая версия: Minecraft Java 1.20.1, Fabric Loader 0.16.10, Fabric API 0.92.2+1.20.1.

Сборка: Gradle 8.7, Fabric Loom 1.6.12, JDK 17.0.21. Java-байткод компилируется для Java 17.

Встроенная текстура: пользовательский `atlas.png` из `atlas.zip`, PNG RGB 1254×1254. Изображение сохранено без изменений; соответствие исходному файлу проверено по SHA-256 и по содержимому готового JAR.

Автоматические проверки:

- Четыре JUnit-теста: обращение по имени, разбор предметов и количества, здоровье/постройки, отмена/управление.
- Пять Fabric GameTest в настоящем headless-мире: выпуск/подбор и NBT владельца; защита от урона и /kill, повторное изменение HP; игровые команды и проверка вложенной административной команды; построение платформы с сохранением существующего блока и отменой; полный асинхронный цикл OpenAI-совместимого HTTP API на локальном mock-сервере, выдающий зачарованный меч через игровую команду.

В игровых тестах используется отдельный временный мир. Тестовый мод не включается в игровой JAR.

Реальный внешний AI-провайдер не проверялся: платный API-ключ не задан. Вместо него проверен совместимый HTTP-контракт и выполнение ответа. Графический клиент Minecraft в этой среде не запускался; визуальное положение в руках, модель и совместимость с шейдерами требуют проверки в игре. Свечение ядра — full-bright, без динамического освещения блоков.

Произвольные игровые команды дают широкие возможности, но не гарантируют безошибочного выполнения любого естественного запроса: это зависит от модели и синтаксиса команд Minecraft 1.20.1. Отмена распространяется на встроенный строитель, а не на команды fill/setblock.
