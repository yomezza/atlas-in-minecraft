Проверка версии 1.2.2
====================

Целевая версия: Minecraft Java 1.20.1, Fabric Loader 0.16.10, Fabric API 0.92.2+1.20.1.

Сборка: Gradle 8.7, Fabric Loom 1.6.12, JDK 17.0.21. Java-байткод компилируется для Java 17.

Встроенная текстура: пользовательский `atlas.png` из `atlas.zip`, PNG RGB 1254×1254. Изображение сохранено без изменений; соответствие исходному файлу проверено по SHA-256 и по содержимому готового JAR.

Автоматические проверки:

- Двадцать шесть JUnit-тестов: разбор чата; валидация полей, HTTP/HTTPS и адреса без протокола; подробный контекст по умолчанию и совместимость со старым JSON; Unicode-контекст; безопасное сохранение файла; пресеты, относительный рост, точные дробные размеры, ограничения и независимость от просьб изменить здоровье/постройку; приоритет ключа из конфига над переменной окружения, запись и скрытие ключа, замена/удаление и проверка недопустимого ввода без вывода значения; валидация формата ответа и расширенного тайм-аута. HTTP-тесты воспроизводят LM Studio-подобный отказ json_object, переход на json_schema и prompt, передачу аргументов действий, маскирование ключа в ошибке, отсутствие повторной генерации при ошибках модели/авторизации/JSON и реальном тайм-ауте; обрезанные ответы отклоняются.
- Девятнадцать Fabric GameTest в настоящем headless-мире: проверки версии 1.1.0, а также плавный рост в небо и уменьшение с тем же ID; сохранение масштаба в NBT; серверные действия колеса; индивидуальная постоянная защита и её сохранение; отсутствие луча/урона до подтверждения; атака только утверждённых целей; два настоящих удара по бронированному врагу; запрет изменения ключа без OP, его скрытие, сохранение при пустом поле, замена и явное удаление. HTTP-тест проверяет Bearer-заголовок с ключом из конфига и выдачу зачарованного предмета после отказа json_object и успешного перехода на json_schema.
- Автоматический тест настоящего графического клиента под Xvfb: Vibe Coding, редактор контекста, колесо, ползунок и точный масштаб, подтверждение атаки и элементы защиты; скрытый ввод API-ключа, сохранение через настоящий серверный пакет, отсутствие ключа в ответном поле, сохранение при пустом вводе и удаление кнопкой ×; сохранение json_schema и тайм-аута 180 секунд через меню и серверный пакет.
- Дополнительная проверка в настоящем одиночном мире: увеличение Атласа над игроком, луч и горящая цель, энергетическая оболочка от третьего и первого лица; открытие/закрытие колеса средней кнопкой мыши; выключение защиты с пустыми руками и повторное включение постоянной защиты с проверкой синхронизированного состояния на клиенте. Скриншоты находятся в `docs/screenshots/`.

В игровых тестах используется отдельный временный мир. Для клиентской проверки из него создаётся `run-clienttest/saves/AtlasPreview`; пользовательские сохранения не используются. Тестовые моды не включаются в игровой JAR.

Реальный внешний AI-провайдер и экземпляр LM Studio пользователя не проверялись. Проверен совместимый HTTP-контракт на локальном тестовом сервере, в том числе ответы 400/422/401, тайм-аут и выполнение игрового действия после согласования формата. Стандартный графический клиент и игровой мир проверены; совместимость с пользовательскими анимациями рук и сторонними шейдерами зависит от сборки. Свечение ядра и поля — full-bright, без динамического освещения блоков.

Произвольные игровые команды дают широкие возможности, но не гарантируют безошибочного выполнения любого естественного запроса: это зависит от модели и синтаксиса команд Minecraft 1.20.1. Отмена распространяется на встроенный строитель, а не на команды fill/setblock.
