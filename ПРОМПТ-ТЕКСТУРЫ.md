Готовый промпт для текстуры Атласа
================================

В мод встроена предоставленная пользователем текстура из `atlas.zip`, 1254×1254 пикселя. Этот промпт можно использовать для её будущей замены. В нём приведена эталонная раскладка 128×128; UV-координаты модели нормализованы, поэтому та же раскладка подходит для квадратного PNG большего разрешения. Например, координата (32,2) из шаблона соответствует долям (32/128, 2/128) полного изображения.
Прикрепи к генератору файл `src/main/resources/assets/atlas_companion/textures/entity/atlas.png` как шаблон раскладки. Попроси сохранить расположение областей.

Скопируй весь блок:

```text
Create a production-ready pixel-art UV texture atlas for an original living
alien companion in a Minecraft Java 1.20.1 Fabric mod. This is a FLAT TEXTURE
ASSET, not a picture of the character and not a rendered 3D object.

Character design: a mysterious floating octahedral artifact with a triangular
silhouette, inspired by the atmosphere of the Atlas in No Man's Sky, with an
original design. Eight detached dark armour faces surround a vivid red crystal
core. No face, eyes, limbs, text, logos, or recognizable copied game symbols.
Materials: near-black charcoal and graphite armour, restrained dark metallic
panel detail, thin deep-red seams, tiny amber accents. The inner crystal is
scarlet and crimson with a small warm orange/ivory hot center. It should feel
ancient, alive, protective, powerful, and slightly unsettling.

OUTPUT: one square PNG, exactly 128 x 128 pixels, sRGB RGBA, lossless.
Every pixel must be fully opaque (alpha 255). Crisp Minecraft pixel art,
nearest-neighbour edges, no antialiasing, no blur, no photorealistic shading,
no baked perspective, no drop shadow, no external bloom, no background scene,
no grid lines, no labels, no watermark. Flat material artwork with readable
pixel-scale details. The provided layout is mandatory.

ATLAS LAYOUT, all coordinates measured from the top-left, zero-indexed:

1. Upper-left 64 x 64 tile: x=0..63, y=0..63, DARK ARMOUR.
   A triangular face uses UV vertices (32,2), (2,62), (62,62).
   Keep all important details inside this upward-pointing triangle.
   Fill the entire tile with charcoal material, including outside the triangle
   to prevent texture bleeding. Add subtle dark panel variations, a thin muted
   red inset border, and a small geometric red rune at the face center.
   Armour remains predominantly dark; do not make the whole face luminous.
   This same face tile is reused on all eight sides of the 3D armour.

2. Upper-right 64 x 64 tile: x=64..127, y=0..63, EMISSIVE CRYSTAL.
   The triangular face uses global UV vertices (96,2), (66,62), (126,62).
   Fill the full tile with red crystal material; keep the strongest details
   inside this triangle. Use crimson edges, scarlet planes and sharp small
   orange-white internal veins. This region is rendered full-bright by code.
   Its glow must read against dark armour without a painted halo.
   This same tile is reused on every triangular face of the inner crystal
   and on three small orbiting crystal fragments.

3. Lower half y=64..127: four solid reference swatches, no text:
   x=0..31 charcoal (#161821);
   x=32..63 dark red metal (#582E2A);
   x=64..95 luminous red (#F72B18);
   x=96..127 warm orange (#FFB654).
   This lower half is reserved and is not currently mapped to visible faces.

Do not draw the complete companion, a hand, a ground plane or an inventory
frame anywhere in the atlas. Do not draw several poses or animation frames.
Rotation, levitation, orbiting fragments and the expansion/contraction of the
red core are performed by the game code, not by the texture. Deliver the PNG
texture atlas by itself, preserving the exact layout of the attached template.
```

Если генератор выдаёт только 1024×1024, сохрани пропорции областей, затем уменьши до 128×128 методом Nearest Neighbor. Мелкие детали при уменьшении могут потеряться — проверь изображение при масштабе 100%. Простое переименование большого файла в «128» размер не меняет.

Как применить
-------------

Замени файл `src/main/resources/assets/atlas_companion/textures/entity/atlas.png` и пересобери мод: `./gradlew build` (Windows: `gradlew.bat build`). Геометрия и пульсация сохранятся. Текстура не создаёт 3D-форму сама: объёмная модель уже реализована в `AtlasMesh.java`. Отдельная emissive-карта не нужна: свечение ядра задаётся рендерером. Это full-bright свечение материала, оно не освещает окружающие блоки и не требует шейдеров.

Вариант без пересборки: положи PNG в ресурспак по пути `assets/atlas_companion/textures/entity/atlas.png`. В корне ресурспака нужен `pack.mcmeta` с `pack_format: 15` для Minecraft 1.20.1.

Не проси генератор добавлять размытую световую ауру вокруг граней: на UV-развёртке она станет частью поверхности, а не настоящим свечением в мире. Точность UV-разметки нейросетью не гарантируется — шаблон и ручная проверка важнее красивого предпросмотра.
